# Техническое задание

## Проект
**Онлайн-меню в Telegram**

## Цель проекта
Создание телеграм-бота для ресторанов, позволяющего пользователям просматривать блюда, добавлять их в корзину, управлять заказом и получать информацию в удобном формате.  
Проект реализуется с использованием библиотеки **aiogram** и асинхронного драйвера **asyncpg** для работы с PostgreSQL.

---

## 1. Функциональные требования

### 1.1 Модели данных

**Пользователь (User)**  
- `id` (Primary Key)  
- `telegram_id` — уникальный Telegram ID  
- `username` — никнейм  
- `is_admin` — флаг администратора  
- `created_at` — дата регистрации  

**Блюдо (Dish)**  
- `id` (Primary Key)  
- `name` — название  
- `description` — описание  
- `price` — цена  
- `image` — ссылка на изображение (опционально, бонус)  
- `created_at` — дата добавления  

**Корзина (Cart)**  
- `id` (Primary Key)  
- `user_id` (Foreign Key → User)  
- `dish_id` (Foreign Key → Dish)  
- `quantity` — количество  
- `created_at` — дата добавления в корзину  

---

### 1.2 CRUD-функциональность

**Пользователь**  
- Автоматическая регистрация при первом использовании бота (`/start`)  

**Кнопки администратора**  

**Блюдо (для администратора)**  
- **Добавить блюдо:** Добавление нового блюда (Reply кнопка)  
- **Просмотреть блюда:** Просмотр всех блюд (Reply кнопка)  
- **Обновить блюдо:** Обновление блюда (Inline кнопка «Обновить»)  
- **Удалить блюдо:** Удаление блюда (Inline кнопка «Удалить»)  

**Корзина (для пользователя)**  
- **Добавить в корзину:** Добавление блюда в корзину (Inline кнопка). При просмотре всех блюд для пользователя кнопка должна отображаться  
- **Просмотреть корзину:** Просмотр содержимого корзины (Reply кнопка)  
- **Удалить из корзины:** Удаление позиции (Inline кнопка «Удалить»). При просмотре корзины кнопка должна отображаться  
 
---

### 1.3 Структура базы данных
**Таблицы:** `users`, `dishes`, `cart`  
**Связи:**  
- `cart.user_id → users.id`  
- `cart.dish_id → dishes.id`
